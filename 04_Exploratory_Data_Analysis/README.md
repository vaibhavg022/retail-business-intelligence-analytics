# Task 04 — Exploratory Data Analysis & Statistical Insights

## Overview

This task focuses on performing Exploratory Data Analysis (EDA) on the Retail Orders dataset to identify statistical patterns, relationships, anomalies, and potential business insights.

## Analysis Performed

* Calculated descriptive statistics including mean, median, standard deviation, and quartiles.
* Examined distributions of Sales, Profit, Discount, and Quantity.
* Used box plots to identify potential outliers.
* Created a correlation matrix and heatmap for numerical variables.
* Performed multivariate analysis using scatter plots and category/region-level comparisons.
* Formulated and statistically tested three business hypotheses.
* Used Pearson correlation and one-way ANOVA for hypothesis testing.
* Documented key observations and business-oriented findings using Markdown commentary.

## Hypotheses

1. Relationship between Discount and Profit.
2. Relationship between Quantity and Sales.
3. Difference in average Profit across Product Categories.
